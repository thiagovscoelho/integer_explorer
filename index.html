Representations by base

Standard bases use 0–9 and A–Z; grouped bases use fixed two-character digits separated by colons.

Base Representation Copy
Notation guide How letters and colon-grouped digits work +

In ordinary bases up to 36, digits follow the familiar hexadecimal-style sequence: 0–9, then A = 10, B = 11, through Z = 35.

For the larger bases, each digit of the outer base is displayed as a fixed two-character group. Groups are separated by colons, and the leading group is padded too. Thus, in any grouped base b, decimal b is written 01:00, and decimal b² is written 01:00:00.
